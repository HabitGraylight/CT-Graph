# 工作台验证记录

验证日期：2026-09-15。

## 自动化

`python -m unittest discover -s tests -v`：**20 项通过**。

- 中英文与品牌归一、品牌与品类的区分。
- 百加得、马天尼、味美思等歧义输入不代猜。
- 中英文单位、公制换算、分数用量、无单位或 oz 的保留。
- 负数、零、非有限数及异常输入拒绝。
- 评分对整体缩放不敏感，识别酸味过强与糖浆过少。
- 未知原料和未建模附加主料不输出总分。
- 12 个框架均可生成完整默认草案。
- 浓糖浆试配减量，已有用量不被覆盖。
- 库存优先、排除条件、备选材料遵守约束。
- 气泡材料不建议密闭摇和。
- 配方比较保留来源；同量公制表达不被误计为差异。
- 所有框架参考链接均能定位到已采集的官方页面。
- HTTP 页面、评分、补全、无效请求和本机访问边界。

`python scripts/validate.py`：原始数据哈希、ID、引用完整性、SQLite 和检索检查仍通过。

`node --check web/app.js`：语法检查通过。
