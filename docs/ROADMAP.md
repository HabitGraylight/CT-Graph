# 路线图 / Roadmap

以实际能力划分状态，不承诺未经评估的完成日期。

## 已实现 / Available

- 本地建议引擎、12 框架、双语原料与品牌身份、七维设计复核。
- 本地试饮与版本修订；六根型导航与条件化设计提示。
- 逐文件发布隔离；中英文项目首页；空数据环境测试。
- 本地 PDF 页检索与定向视觉阅读流程。

## 下一阶段 / Next

- 目标版本感知的评分：例如干/湿马天尼分别有明确参照。
- Flip 与蛋类质地结构：先定义可验证约束，再新增模板。
- 工艺状态：原料批次、冰面带水、过滤损失和分时感官记录。
- 知识候选的矛盾与证据等级管理；扫描页的本地 OCR 与人工核验。
- 多语言工作台；当前双语范围是 GitHub 项目介绍。

## 研究阶段 / Research

- 基于带条件的香气档案生成候选，避免把共有分子当作喜好证明。
- 随机顺序、盲测和足够重复的试验数据；评估可识别性后再拟合因果模型。
- 公开合成基准；真实个人数据不进入公共训练集。

No fitted causal model or automatic molecular taste predictor is currently claimed. Roadmap entries describe planned work, not released functionality.
